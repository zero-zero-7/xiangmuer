# 四序颐养

中医养生科普 + 轻社交 Web 应用（手机端优先，兼容桌面）。前端为单文件 `四序颐养.html`，后端 FastAPI + MySQL，所有账号、内容、点赞、评论、收藏、举报等均为数据库中的真实数据。

## 功能

### 用户端
- 账号体系：用户名 + 密码注册 / 登录，手机号验证码登录，注册后自动入驻数据库
- 四大板块：饮食食疗、运动功法、经络穴位、情志睡眠（官方养生方案 + 权威链接）
- 颐养社区：用户投稿（图文）、点赞 / 取消点赞、评论与二级回复、收藏、举报
- 我的：我的投稿（审核状态与驳回原因）、我的点赞、我的评论、收藏分组、修习足迹、笔记、体质测试、消息中心、设置
- 消息通知：审核通过 / 驳回、下架、封禁、评论、系统通知
- 账号安全：注销申请 7 天冷静期，期间可撤销；到期清除投稿与评论并显示「已注销账户」
- 健康免责声明：首页弹出 + 详情页底部常驻

### 管理端（角色 `admin`，入口在「我的 - 管理后台」）
- 数据看板：注册用户、今日新增、官方方案、用户投稿、待审核、已通过、累计点赞、待处理举报
- 内容管理：审核通过 / 驳回（附原因）、置顶 / 取消置顶、下架、删除
- 用户管理：搜索用户、临时封禁（自动解封）/ 永久封禁 / 解除封禁
- 举报处理：删除内容、下架内容、封禁作者、忽略
- 分类标签：4 个固定一级分类启停、人群 / 节气 / 调理方向标签维护
- 所有审核与处置操作写入 `audit_records` 审计表

## 目录结构

```
四序颐养.html          前端单文件应用（hash 路由，同源调用 /api）
启动四序颐养.bat        Windows 一键启动（8001 端口）
server/
  app.py               主服务：内容、帖子、评论、收藏、消息等
  api_v2.py            账号 / 管理后台 / 审核 / 举报 / 分组 / 注销接口
  db.py                MySQL 连接、建表与字段迁移
  seed.py              首次运行的演示数据
  migrate.py           分类标签、管理员账号、内容状态迁移（幂等）
  security.py          PBKDF2 密码哈希
  requirements.txt
  .env.example         数据库连接示例
```

## 快速开始

1. 准备 MySQL 5.7+ / 8.x，创建数据库可省略（首次运行自动建库 `siyu`）。
2. 安装依赖：

```bash
cd server
pip install -r requirements.txt
```

3. 配置数据库连接：复制 `server/.env.example` 为 `server/.env`，填写真实密码：

```
DATABASE_URL=mysql://root:你的密码@127.0.0.1:3306/siyu
```

4. 启动（Windows 可双击根目录 `启动四序颐养.bat`）：

```bash
cd server
python -m uvicorn app:app --host 127.0.0.1 --port 8001
```

5. 浏览器打开 <http://127.0.0.1:8001/>

首次启动会自动建表、导入演示数据、创建管理员账号与分类标签。

## 内容状态流转

```
用户投稿 → pending（待审核）
        → approved（通过，社区可见）
        → rejected（驳回，附原因，仅作者可见）
        → offline（管理员下架，仅作者与收藏者可见）
```

封禁用户可登录浏览，但点赞、评论、投稿、收藏会被拒绝；其历史内容与评论对他人隐藏。临时封禁到期后自动解封并发送站内信。

## 部署到 GitHub / Gitee

```bash
git init
git add .
git commit -m "feat: 四序颐养 账号体系、真实 UGC 与管理后台"
git branch -M main
git remote add origin https://github.com/<你的用户名>/siyu-yiyang.git
git push -u origin main
```

Gitee 同理，把 `origin` 换成 Gitee 仓库地址即可。仓库已通过 `.gitignore` 排除 `server/.env`，请勿提交数据库密码。
